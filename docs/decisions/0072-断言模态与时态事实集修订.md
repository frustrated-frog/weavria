# 0072 断言模态与时态事实集修订

状态：已实现、显式启用；算法契约通过，真实模型形成尚不稳定，2026-11-01。

## 技术问题

逐候选、单目标的记忆更新会把未裁定的竞争说法漏掉，也无法在明确纠错后整体更新争议。只有再试一次模型或再加一条拒绝规则，不能解决事实组织问题。本轮建立可计算的事实集合：语言解释负责识别陈述及对应属性，宿主负责组织竞争值、切分时间区间、合并重复支持与实施集合修订。

## 决策

显式启用事实集策略，保留上一版逐目标策略作为基线。提取表示区分 asserted、reported、hypothetical、quoted：报告一条实际存在的规则不等于认可它为真，但应保留其内容与来源；假设及任务中的引用不会成为事实。模态按候选持久化，不混入适用条件。提取仍是一轮结构化模型调用，独立复核继续检查语义。原文由宿主无损分片并标号，模型选择证据编号，宿主生成精确字面引用；模型不再抄写引用和猜测字符偏移。

经实体、属性与条件对齐后，按精确条件键分组。在每组中构造有效区间的交叠连通分量，处理与新候选相连的分量。用端点扫描把时间线切成状态不变的单元；同时有效的不同值构成竞争，状态为 contested，不能按时间新旧选择赢家。相同值的重复支持不提升置信度。明确且有来源的集合纠正才会在指定区间替换所有竞争值；不在纠正区间的前缀、后缀及其他条件保留。多个相互矛盾的纠正重叠时不按候选顺序裁决。

复核的模型视图用快照编号、一次字段对应与引用编号表示关系，宿主展开为 resolutions、目标版本和完整字面证据。字段对应与值等价分开：只有 equivalent 可以复用旧值；conflict/change/correction 的值字段对应始终保留候选新值。集合纠正可选择已持有正确值的成员作锚点，并仍修订整个受影响集合。宿主从完整快照计算交叠闭包和实际受影响目标，不让模型手工列出分片。完整性检查是算法的输入一致性要求，核心计算是区间分解、竞争传播和最小分片合并。

编译结果是一个原子 batch：撤回被重写版本，增加计算出的事实分片。为保持残余争议，MemoryMutation v2 的 add 可带 initial_status；v1 序列化完全保留。提取 v3 记录模态，Review v5 记录集合纠正及宿主生成收据。数据库 DDL 与 Assertion v1 不变。旧版本作业按其原策略读取，恢复不得切换策略。Journal 保存旧事实和更新来源，支持历史 as-of 与投影重建。

未知有效时间不是负无穷。全部未知时按一个不可分的未知单元处理；已知与未知交织的修订暂不猜测时间。容量超过现有批次上限时不提交半个分量。新算法受原来的总期限、取消、存储事务和 CAS 重评机制约束。

## 替代方案

单目标依次覆盖会产生顺序依赖，且不能原子消解多个竞争说法；直接清空同主题会删除条件例外和未纠正时间段；只用模型输出最终记忆集合会把时间差集与来源保留交给非确定性生成。全概率信念网络需要来源独立性与校准证据，目前并无足够依据。因此采用语义对齐加确定性时态集合计算，保留可替换策略，不宣称自动判断事实真伪。

## 验证路径

确定性测试覆盖三方竞争、同批竞争、局部纠正、条件例外、等价证据、相邻区间、未知时间、输入顺序、CAS 后重新计算、重开和重建。真实模型使用原自然形成数据和新的多方/局部纠正材料；比较逐目标基线与事实集策略，记录失败、调用与成本。模型识别模态及完整纠正的准确率属于实验结论，不能由类型和单元测试证明。
