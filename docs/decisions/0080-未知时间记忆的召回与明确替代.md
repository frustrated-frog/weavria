# ADR 0080：未知时间记忆的召回与明确替代

日期：2026-11-02。问题来源：M1-04、M1-05 的自然形成→跨会话消费失败。

## 决策

HarnessMemory 增加 `include_unknown_time=False`，经 from_model、from_config 传递给现有
MemoryContextSource。默认保持严格有效时间语义；需要当前已知约定的宿主显式开启，模型收到
完整组、来源与 unknown 时间字段，不能将它当作已证明当前有效的事实。两组 M1 复测统一开启，
manifest 记录该选择；问题、评分和预算不变。不开启时仍排除 unknown，不用保存时间冒充生效时间。

ConservativeMemoryAdmission v4 允许已审阅的 change 替代 active 的未知起点记录：新起点必须
明确且不晚于来源发生时间，条件和同一事实键仍须一致，终点不改变。已知起点的旧区间继续采用
原来的半开区间尾部切分规则。未来变更不能提前撤销 unknown 旧记录，仍延后处理。

复用 ADR 0039 已有的 supersede：旧起点未知时，旧记录的新知识版本变为 retracted，新值进入
active；不编造旧值的开始或结束时间。旧知识快照仍可查到旧约定，当前严格查询只能证明新起点
之后的新值；不能从当前知识断言新起点之前的旧值一定有效。撤销是当前知识退役，不是物理删除。

## 取舍、兼容与验证

不扩展 MemoryAssertion 的区间类型，不修改归约器与持久化 Schema，不重写旧 journal；旧数据
和旧形成计划按原版本保持原结果。自动修改旧 deferred 计划会破坏幂等，因此本轮不进行这种迁移。
未选用该策略的低层读取保持原样。宿主也可继续选择严格时间查询。

验证包括：自然输入形成 unknown，经工厂关闭重开后可选召回；明确当前变更的准入、原子提交、
重复提交、旧知识快照、严格时间查询、重建和重开；未来变更仍被延后。Fake 只验证执行契约，
真实模型收益以冻结任务完整复测为准。取消与并发沿用现有形成事务和 CAS 契约测试。
