# 摘要保真探针与压缩成本的配对评估

## 问题与本阶段结束条件

0099–0101 已经提供来源图、摘要工具、压力建议和补读预检，但真实资料审阅任务仍没有证明摘要收益。该任务要求精确引句，不能将“模型没有调用摘要”直接解释成决策失败。固定字节门槛也无法回答：节省的空间是否以丢失条件、例外或适用范围为代价。

本阶段先建立独立的质量与成本信号，不继续增加生产开关。结束条件是：用冻结原文和独立标签执行三组配对问答；把来源读取能力、信息损失、模型格式故障与成本分开；真实摘要必须通过已有工具和来源图；包含朴素基线、故障测试和真实模型结果。它是一个质量评估机制，不代表自主压缩时机或长任务已经修通。

## 契约与数据流

`evaluation/summary_fidelity.py` 提供版本化的 `FidelityCase`、`FidelityResult`、`FidelityComparison`，以及生成问答请求、评分、配对比较的独立函数。用 Pydantic 在数据与报告边界校验，不再定义一份平行的 Dataclass Schema。公开 API 从 `weavria.evaluation` 导出；Core、Runtime、Context 不导入此评估模块。

一次实验按以下步骤流转：

1. 从已有 M1 冻结 corpus 加载原文，验证文件 SHA-256 与标签支持原句。新增数据集含 4 份完整资料、24 个探针，包括事实、条件、例外、作用域和未说明问题。只有资料来自真实文件，不将填充文本冒充长任务。
2. 将原文通过正常只读工具接受为 Artifact。摘要生成请求只包含任务、原文和来源地址，不包含探针、参考答案或支持原句标签。
3. 显式调用一次模型生成 `SummaryDraft`；核验来源、修订和文本预算后，交给现有 `compact_context` 验证。随后由 `SessionContextCompiler` 构造实际 `ContextSummaryView`。生成失败不修复、不重试、不冒充成功摘要。
4. 分别把完整原文、首尾摘录、摘要视图交给独立问答请求。摘要组不能回读原文或继承生成阶段的对话。首尾摘录按摘要整个视图的 UTF-8 字节数限额，来源元数据不从摘要成本中隐去；生成失败时保留原文/预设预算摘录结果，不声称两组实现了摘要尺寸配对。
5. 问答请求只看到表示与问题，没有答案标签。回答必须完整覆盖问题 ID，每项给短答案及当前表示中的连续引句；材料未说明时两项均为 null。模型调用使用既有 `call_model`，每轮有时限，没有隐藏修复调用。
6. 评分端依据冻结标签分类，再与同次实验的原文组配对。输出身份摘要、状态、探针结果与供应商成本；默认不保存模型原答或原文。显式 `--representations-dir` 可在新目录保留公开冻结资料的表示，便于复核，不能覆盖原文件。

## 评分算法与质量门槛

重复 ID、漏题、未知 ID、额外字段、非法 JSON，使整个问答批次成为 `invalid_output`，不能通过减少评分分母得到更高分。超过有界响应大小也拒绝。合法回答逐题分类：

| 类型 | 判定 |
| --- | --- |
| supported | 命中冻结答案别名，且引句确实存在于当前表示 |
| omitted | 原题有答案，但模型表示无法回答 |
| incorrect | 给出的答案不符合冻结标签 |
| unsupported | 答案正确，但没有当前表示中的真实引句 |
| correct_abstention | 原文也未说明的问题，模型拒绝猜测 |
| unsafe_assertion | 原文未说明的问题，模型仍给出答案 |

别名归一化只折叠空白、大小写，不删除否定词、单位或标点来宽松匹配。若模型表示是 JSON，引句既可以匹配字面表示，也可以匹配该 JSON 中一个解码后的字符串，避免引号和换行转义制造假遗漏；不拼接字段，不读取引用指向的原文。引句连续命中不等于语义蕴含证明：模型可能给出正确标签却引用不相关句子。当前检测的是冻结探针上的可回答性，不把 `supported` 泛化为整份摘要无幻觉。

配对比较先检查相同 case 摘要与问题集合。原文组不能正确回答的题进入 `baseline_unreliable`，不直接归因为压缩损失；但任何不可靠基线都会阻止 `eligible_on_probes`。原文能回答、候选不能回答的题记为 lost。已出现 lost 或对未说明内容的断言时为 `regression`，节省多少 Token 都不能抵消它。

仅在全部探针通过配对、没有错误断言、输入 Token 确实减少且生成成本已知时，报告 `eligible_on_probes`。这只表示值得进一步验证的候选，不修改生产策略、不发布摘要可信等级。失败试验为 `invalid_trial`，基线或成本不可靠为 `inconclusive`，输入未节省为 `no_savings`。

## 成本与执行语义

使用同一供应商实际报告的原文问答输入 Token、候选问答输入 Token、摘要生成总 Token。缺失 usage 保持 unknown，不填零，不以 `len(text)` 换算 Token。问答提示与问题保持相同，所以输入差值反映表示替换在这个请求里的成本变化。

当输入节省 S>0 且生成成本 G 已知时，报告 `ceil(G/S)`，表示反复复用同一个表示时，理论上摊销摘要生成 Token 所需的次数。它不包含离线质量评估的开销，也不预测真实 Agent 还会复用几次，不等于经济费用、延迟或最终任务收益。完整报告另保留每次供应商调用成本，可计算本次实验实际总消耗。

每个资料最多一次生成与三次问答，每次模型上限 30 秒，每个资料外层 150 秒。超时、供应商失败、非法模型输出通过统一模型错误边界记录，取消直接向上传播并等待清理；CLI 用 finally 关闭 HTTP 客户端。没有并行 Agent、自动调参、运行期模型审阅或 Memory 写入。持久报告使用独立 v1 契约，不改变已有 Session/Context Schema。

## 替代方案与研究依据

没有采用仅比较字节压缩率、ROUGE 或是否存在引句：它们不能单独识别答案中的条件与例外丢失。也没有用一个自由生成的模型评分来代替所有标签，否则评分漂移与候选质量难以区分。冻结探针的成本是人工标注和有限覆盖，优势是失败位置、分母、版本和对照都可复核。

思想参考为问答式事实评估：[QAFactEval](https://aclanthology.org/2022.naacl-main.187/) 强调问题生成和可回答性分类的影响；[QuestEval](https://aclanthology.org/2021.emnlp-main.529/) 用问答比较摘要和来源的信息。访问日期：2026-11-04。本实现使用人工冻结的问题与答案，没有复现它们的自动问题生成、训练模型或原论文实验，不称为论文结果复现。

## 验证范围与下一步

确定性测试覆盖标签隔离、冻结来源漂移、完整题集校验、条件遗漏/错误/无证据的区别、正确拒答、基线答错的归因、缺失成本、没有节省、跨 case 拒绝、取消/时限清理、非法生成的零重试，以及经过真实摘要工具和来源图得到视图的端到端路径。

真实实验命令与结论维护于[摘要保真与压缩成本实验](../摘要保真与压缩成本实验.md)。首批文件都是当前项目的文档与源码，不代表跨领域泛化；问题以短答案为主，无法覆盖复杂推理、所有幻觉或合并多层后累积的语义损失。下一步应根据实际丢失的探针研究保留/回取机制，并加入独立领域与新任务；有证据后才讨论把成本收益信号反馈给生产压缩决策。
