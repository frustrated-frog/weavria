# 0071 记忆形成的有界修复与引用复用

状态：已实现、显式启用；记忆整体尚未成熟，2026-11-01。

## 问题

上一轮真实形成存在三类不同故障：供应商响应被本地 Action 协议拒绝、候选 Schema/引用不合法、复核在 8192 输出额度处截断。重复调用整个形成流水线会浪费已接受提取；仅提高额度不能消除重复长引用及输出结构复杂度。

## 决策

显式 `MemoryGenerationPolicy(max_repairs=1)` 启用有界生成路径，最多允许两次修复（总调用三次）。提取和复核各自在已分配的同一 monotonic 期限内运行；没有为每次修复重发完整预算。父形成期限及 CAS 重评次数上限继续生效，取消传播不变。

只修复 INVALID_MODEL_RESPONSE 中允许修复的协议故障，以及当前阶段候选 Schema、引用和完整复核覆盖错误。诊断使用固定代码，不把非法响应、原始异常或隐藏推理放入后续提示。来源、候选、快照及目标 Schema 固定，重试不获得更大作用域。截断、超长结果、鉴权、依赖和输入预算故障不重复调用同样的路径。

新复核 wire v1 以候选自身 citations 的整数编号替代逐字段重复引用文本。宿主按冻结的候选快照还原为原有 `MemoryFieldMatch`，再执行 Review 校验和已有准入。负数、越界、重复引用及跨候选猜测引用均不能被模糊补全。模型 wire 仍限制为 64 KiB，展开引用单独限制为 256 KiB，不能通过短编号放大工作集。该优化不等于语义压缩，不丢弃任何候选或既有事实，也不取消全文复核。

模型表示与持久表示分开：模型无权生成尝试收据。宿主记录请求/响应摘要、固定失败代码、耗时和顺序。成功提取以 MemoryExtraction v2 保存收据；成功复核以 MemoryReview v4 保存收据。旧提取 v1、Review v1–v3 的序列化不新增字段；数据库 DDL 不变。失败通过 MemoryFormationError.generation 向调用方暴露收据，评测器保存它；失败收据不是已接受记忆，不推进源游标。取消或父期限打断时不保证形成完整收据，原已保存阶段仍可恢复。

新配置写入 adapter/pipeline 版本。恢复不能静默切换算法。默认保留无修复、完整引用模式作为基线。尝试额度约束一次阶段调用，不宣称跨人工恢复的永久费用上限；CAS 重评每次重新分配局部尝试，但始终受父总期限和已有 max_attempts 限制。

## 替代方案与验收

不自动包裹裸 JSON、不接受半截结果、不扩大 Schema、不无限重试、不在候选未接受时先写部分事实。完整引用仍是可对比基线。首轮实现不分拆多候选的联合修订判断，不引入另一个规划模型。

验证：协议错误后的单次修复、非法引用后的重新生成、截断与依赖失败不重试、次数/总期限/取消、完整尝试收据落库与重开、引用编号按候选绑定、语义拒绝不触发重试、老版本序列化。真实任务保持原数据与预算，对比调用、耗时、输入输出 Token、形成和消费结果；不能只报告修复后的最后一次成功。
