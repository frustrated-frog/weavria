# 0029 任务感知的联合上下文编译

## 状态与范围

已实现（2026-10-23）。基于 `bb17ea0`，在 `codex/context-compiler-v1` 完成首个可显式启用的切片；默认行为保持原有字节选择路径。源码流程、兼容说明、运行方式和实测结果见 [上下文编译与信息恢复](../上下文编译与信息恢复.md)。

问题：既有会话投影先占用独立字节预算，当前 Run 再选择工具证据；信息价值不能跨两类候选比较。字节数不能描述模型窗口，需求状态变化也没有参与信息分配。虽然两套选择器都在每次决策前调用，仍可能保留重复的旧内容，省略当前需要的早期细节。

## 机制与边界

1. 权威 Event、ConversationTurn、Artifact 不改变。编译器从这些原文构造临时中间表示：不可拆的工具调用与回执、完整历史交互、各自的表示候选、来源地址和依赖边。每次决策重新选择，不把上一次有损视图作为下一次的输入。
2. 会话与当前工具证据共享一个完整 SessionRequest 预算。表示包括原文、精确字符区间/JSON Pointer 片段、引用和省略；本轮不生成抽象摘要。历史片段新增独立版本的区间契约，旧前缀契约保持可读和原样序列化。
3. Harness 把 TaskFrame/NeedLedger 投影为通用信息需求：检索文本、优先级和已验证的证据地址。编译器不了解业务领域或 Harness 的内部 Schema；这些提示不能替代用户指令、授权或完成验收。缺少语义投影时仍按当前任务自主检索。
4. 使用预算约束的多表示选择。目标函数为非负特征的最大覆盖之和，已覆盖的查询词/相同片段不因重复出现重复获益；来源冲突的已知证据地址有各自覆盖特征。候选评分从实际原文计算，不由应用预标记答案。依赖祖先的最低表示计入边际成本。分别运行收益密度和绝对边际收益贪心，选择最终效用较高的可行解。它是确定性近似，不声称在依赖闭包、多表示和实际分词成本下具有经典背包近似界。
5. 当前指令、任务、任务观察、控制反馈、最近交互条目及最新工具反馈为硬约束。最低表示装不下时明确耗尽预算，不能静默删掉失败。最新结果即使没有词面相关性，也在可行时先分配一个实际数据表示，避免数字或不透明 ID 永远只留下引用。选择与最终发送使用同一个完整请求；计量包含适配器的协议提示，不只计算选中的正文。
6. Token 预算显式配置窗口、输出预留和安全余量。适配器使用显式指定的 tokenizer，不根据供应商名称猜测。对正文使用真实 BPE 计数，对供应商消息框架使用声明的上界；这是有条件的估计，不等同于服务端 usage。新增可选 `tokenization` extra，不引入 Agent 框架。工具准入另用保守的编码字节上界，保护下一轮最低回执容量；不能把精细选择的 Token 估计当作未来未知结果的保证。
7. 编译记录包含策略版本、需求/输入/输出摘要、表示选择、预算、计量方法和覆盖缺口，通过新的版本化 Session 事件与请求快照在同一事务保存，模型发送前完成。无原文正文，不记录私有推理。取消、持久化失败、任务修订沿用现有 Runtime 所有权与提交边界。
8. 历史原文恢复复用受 Session 约束的 `read_session_history` / `read_session_source`，当前成果使用 `read_artifact`。编译器不绕过这些边界自动把过去来源认作当前执行的新证据。索引可缓存，选择不能跨修订复用；缓存属于单 Run，有显式大小边界。

## 替代方案与取舍

- 保持两个固定预算：实现简单，但无法处理跨会话与工具证据的资源竞争，保留作既有基线。
- 直接添加摘要模型：会同时引入事实归因、摘要版本和取消/费用语义，先建立原文与视图分离以及预算决策，后续再扩展。
- LLM 为每条历史打标签：可能改善语义召回，但额外模型调用和不可校准评分不适合作为本轮唯一选择器。
- 精确全局优化：多表示依赖选择本身具有组合复杂度，且完整请求的 BPE 成本不严格可加；本轮以可解释近似和小规模穷举参照暴露最优性差距。

## 技术证据

访问日期：2026-10-22。以下仅为思想借鉴，不宣称复现或超过原项目。

- [ACE v1](https://arxiv.org/html/2606.31564v1)：每步选择历史表示，原文维护层与模型视图分离。本实现用确定性预算分配与精确片段，未复现其 LLM 编排/摘要机制。
- [ACON v3](https://arxiv.org/html/2510.00615v3)：通过压缩前后失败轨迹优化压缩指引。当前缺少足够真实任务轨迹，不引入训练或在线自改策略，也不借用论文收益数字。
- [Pi compaction，4270522473e677ddba7b093caa0064a3df51d459](https://github.com/earendil-works/pi/blob/4270522473e677ddba7b093caa0064a3df51d459/packages/coding-agent/src/core/compaction/compaction.ts)：切点不能拆散工具回执，压缩记录保存边界；视图改变后旧 usage 不可直接代表新视图。本实现每次重算完整发送内容，不沿用旧窗口 usage。

## 契约演进与验证结果

新增 `LocatedTextExcerpt` v2，与原有 `TextExcerpt` v1 共存；原有前缀值原样序列化。新增 `SessionContextCompiled` v1 事实，只用 `SessionEvent` v4 承载，其他事实继续写 v3。启用编译器的 Run 配置快照用 v2 保存编译参数与计数器版本，未启用时仍用 v1。旧数据库原文和事件不改写，无 DDL 迁移。旧读者需升级才能理解新事件和区间表示。

回归测试覆盖配对、闭包、精确区间、两个预算、不透明值、失败最低回执、任务修订、来源身份、缓存污染、取消和持久化失败。通过 SQLite Session 验证多轮执行、按位置回读、重启后读取与每次模型决策前重编译。浮点数组测试验证传输 JSON 编码不会破坏未来回执的保守字节上界。

冻结 8 个由真实项目技术原文构成的合成轨迹、16 个目标短语，比较完整、新近优先、独立相关性和饱和覆盖。在 2,600 Token 窗口下，覆盖保留 13/16，两个选择基线各 9/16；覆盖与相关性的总输入量分别为 15,709 和 15,697 Token。在 1,800 窗口下两者持平，4,000 下覆盖仍停在 13/16，保留失败案例。完整原文策略仅 1/8 可放入预算。具体语料摘要、逐项结果与成本见讲解文档及可复现命令。

实验只验证信息交付；没有真实 LLM 成功率结论。小规模穷举测试说明密度贪心的特定陷阱被覆盖，不证明全局最优。当前限制包括词面检索、每个历史文本单一区间、有限候选窗口、同步索引的取消延迟和保守准入。后续机制应针对可复现失败深化，不能用扩大接口或测试数量替代真实任务收益。
