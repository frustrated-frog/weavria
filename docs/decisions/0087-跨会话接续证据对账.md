# 跨会话接续证据对账

宿主可以对显式任务接续启用 `continue_task(..., evidence_reconciliation=True)`。与原来的历史状态提示相比，对账视图给出可复用、待复查或缺失的判定及原因。框架使用最近一个 Run 的需求、证据账本和任务来源链中重新授权的 Artifact 计算对账。

可复用要求先前需求已取得满足覆盖契约的资料。框架核对原文运行标识、调用标识、摘要和 JSON Pointer。需要当前时点、依赖其他需求、证据已过期、引用不可用或覆盖不足时要求复查。没有已接受绑定时标记为缺失。大结果当前仅交付来源引用，接续模型没有正文时也要求复查。授权撤回沿用原接续入口的拒绝规则。

任务视图会在当前解释修改同名需求契约、或用户修订任务时撤销历史复用提示。不同 Run 的局部需求 ID 不参与契约摘要。跨 Run 语义等价和未匹配需求由模型根据当前目标判断。对账结果属于上下文提示，独立的新 Run 仍执行原有证据准入和完成验收。

确定性验证对照同一个阅读任务的原接续视图和证据对账视图。两组都读取剩余文档，对账组额外验证模型实际收到原文地址及可复用判定。覆盖变更、时效、来源不可用、权限撤回和版本冲突均有回归检查。当前开关默认关闭，真实模型的重复调用和完成质量仍需对照评测。
