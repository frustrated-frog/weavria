# 上下文压力建议与多来源联合替换

## 问题与决策

0099 提供了显式摘要工具与分层来源图，但模型缺少本轮容量反馈；覆盖分配器的单来源局部交换也无法覆盖某些多来源替换。这里扩展搜索邻域，并向模型交付可执行范围的建议。通过 `ContextCompilerConfig(summary_guidance=True, semantic_compaction=True)` 显式开启，旧配置继续使用原有行为。

本轮机制验收要求：建议范围确实可见、预算与执行配对不被破坏、多来源交换能够改善一个可穷举验证的反例、摘要经过真实 Harness 持久化后可合并和展开。真实任务收益另行报告，不能由这些机制测试推定。

## 压力建议

编译器先将 v9 协议计入请求，并为建议预留 1024 字节及保守的同量 Token 空间，再执行普通分配、计算压力：包含控制/后续执行预留的请求达到 Token 或字节预算的 80%，或者任务相关原文只能被摘录/引用/省略。后者是信息降级信号，不代表所有原文都必须交付。

候选必须来自当前选中的正文表示。原文使用 `EvidenceDelivery` 中的精确范围；交叠和相邻窗口合并，不能跨越未读缺口。第一层摘要可以整体合并；更深节点的模型视图已经展开叶子，故本策略暂不自动推荐其完整直接边，模型可先用 `read_artifact` 读取后自主压缩。

候选每项至少 1 KiB、最多 128 KiB，按体积与地址确定性排序，最多四项、合计 4–256 KiB。它们是有界策略门槛，尚未经任务收益调优。模型负责陈述、条件和例外的提炼；系统不自动填写摘要正文。

已有有效摘要覆盖的范围不再次推荐；相同任务修订中已尝试的精确范围不重复催促。这个去重只作用于建议，不能成为禁止工具合法重试的 Policy。任务改写后重新计算。没有私有冷却计数器，状态来自接受记录。

建议有 `idle`、`compact`、`merge`、`attempted` 四种状态。最终释放预留并对完整请求再次计量；具体来源放不下时降级为简短压力提示，提示也放不下时撤回。进入仅允许最终回答的 synthesis 阶段后，不生成建议且释放全部建议预留。最低必需正文、恢复范围和反馈配对不会被降低；预留会减少普通候选的可用空间，这一成本必须参与策略对照。Session 存储核验建议与编译报告一致，并检查原文范围属于本轮交付清单、摘要父节点确实可见。建议不是授权、强制动作或任务完成条件。

## 多来源联合替换

摘要单元声明已经验证的父节点和原始叶子作为替换组。分配器仍运行密度/绝对收益两路贪心，再用有界邻域考虑：

1. 将一组来源降到允许的最小表示，插入摘要；
2. 尝试利用释放的空间补入另一单元；
3. 对完整候选重新计量，仅接受覆盖效用增加，或同效用下成本降低的结果。

来源引用闭包、恢复保护范围、最新反馈的最低表示始终保留。摘要仍仅按实际可见词项计分，维持 0.7 权重，没有添加虚假的来源覆盖分数。联合搜索最多两轮，消耗两路贪心之后剩余步数的一半，随后保留单来源交换。搜索可以取消，耗尽预算时保留可行结果，不承诺全局最优。

确定性反例中两份原文各覆盖 `shared=18` 与独有需求 `2`，成本各为 5；第三份材料提供新需求 `10`，成本 8。摘要覆盖前两份的 0.7 倍词项，正文成本 2，两个来源引用各成本 1，容量为 12。原算法停在两份原文、效用 22；联合替换可交付摘要和第三份材料，效用 25.4，与穷举最优一致。这是选择算法证据，不是模型正确率指标。

## 兼容、失败与边界

- 请求新增 v9 的 `summary_advice`，报告新增 v15；v8/v14 以及更早版本保持原样序列化。
- 旧 `semantic_compaction=True` 默认不启用建议与联合替换，便于消融对照。
- 摘要生成仍走普通工具、预算、取消、指纹、持久化与任务策略。任务完成后多余压缩可以被既有收尾建议拦下。
- 大型工具结果在压缩机会出现前就超过反馈预留、任务需要未显示原文、模型不采用建议、摘要语义损失等问题仍可能发生。本策略不绕过预算准入，也不总结尚未显示的材料。
- 不增加依赖、后台模型调用、Memory 写入或跨 Run 隐式状态。

## 验证与证据

定向测试覆盖交叠窗口、未读缺口、建议去重与任务修订、窄预算撤回、可执行建议、联合替换及精确小规模最优解、两层摘要与原文展开、SQLite 重新打开后的幂等返回。真实任务入口新增 `guided` 组和跨全部冻结资料的 `--audit` 任务。审阅评分只核验来源覆盖与连续原句，综合判断的语义正确性仍需独立评审。

设计延续 [0099](0099-带来源的分层语义压缩与原文展开.md) 的第一方研究来源；本轮依据现有实现和失败实验深化，没有新增论文复现主张。实验结论维护于 [执行过程与实验](../分层语义压缩的执行过程与实验.md)。
