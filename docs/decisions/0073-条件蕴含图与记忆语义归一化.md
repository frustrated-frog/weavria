# 0073 条件蕴含图与记忆语义归一化

状态：已实现、显式启用；形式语义与生命周期验证通过。冻结的 8 例独立验证中严格评分由 2/8 至 5/8，仍有形成失败与评分局限，2026-11-01。

## 问题与范围

现有字段对齐在 qualifier 对 qualifier 时仍比较字符串相等，因此“同一个条件的不同表达”无法进入相同事实集。直接放开字符串检查又无法区分等价、单向包含和互斥。解决的是同一实体、属性下的条件合取归一化，不引入领域词典或固定属性本体。

## 决策与算法

条件键值对作为带来源侧的原子命题，候选与目标构成局部有向图。语义解释器提供 equivalent、entails、disjoint 边（左右节点显式标注所属侧，允许同侧关系）；未判断的关系不生成边。相同键值可产生确定性的等价边。主体与属性仍独立对齐，不能从条件相似推断实体相同。

宿主用多源 BFS 计算条件合取的最小闭包，并保存到达路径。等价条件循环允许存在；单个命题可以蕴含多个条件，不要求错误的一一匹配。分别检查两侧闭包与联合闭包中的互斥对：一侧自身矛盾时返回 inconsistent；仅联合矛盾时为 disjoint；两侧互相覆盖全部条件时为 equivalent；单向覆盖只表示已证明该方向，不能把缺失反向证明称为严格子集。否则为 unknown。空合取表示没有显式限制。有限图的结论仅相对于给定语义边，不证明自然语言边本身正确。

只有 equivalent 才将候选条件复用为锚点的规范表示。主体、属性及值的对齐与条件推理分开；correction/change/conflict 保留新值。来源、时间、模态与原候选完整保留。非等价的同族新事实保留原条件；已指定覆盖目标的候选不擅自改成覆盖不同条件。仍由现有时态集合算法负责竞争与部分区间纠正。

新增 MemoryReview v6 保存条件关系、目标版本与原文引用；旧版本序列化不变，Assertion/DDL 不变。新策略必须显式启用并绑定 pipeline version，CAS 后重读快照重算；取消与失败沿用可恢复形成作业。图只活在一次冻结快照内，不把一次语义判断变成全局词典。

## 替代方案与局限

不采用字符串同义词表：会随应用膨胀。不采用 embedding 相似度直接合并：相似不能区分包含与互斥。不要求模型直接给最终 canonical qualifiers：这会隐藏丢失的条件。也不假装实现通用一阶逻辑：当前只支持正原子合取、一元蕴含和互斥，不能处理析取、量词、多个前提共同推出一个条件或自动拆分隐藏在属性里的条件。

本轮不删除被错误提取为条件的来源信息；来源角色和命题分解仍需下一层机制处理。算法深度在于组合已有局部关系并产生可重放证明，不以放宽校验或多加一次审核作为收益。

## 验证

确定性部分用穷举布尔赋值独立验证蕴含与互斥、闭包路径和输入顺序不变性；集成覆盖同义条件的真实写入、单向包含不覆盖、SQLite 重开/回放、取消及 CAS。真实模型固定提取器和模型配置，比较旧字符串策略与新关系图；开发集与预先冻结的独立验证集分开，验证集结果不用于本轮修改提示。数据使用多个非金融场景，不宣称生产流量或盲测。
