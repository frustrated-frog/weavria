# 0096 共享数据源故障与有限交付

FinScope 公司、新闻和事件搜索共用服务。上游返回 502 时，按工具参数分别重试会把同一服务故障当成不同取证机会。这个问题也适用于其他共享数据库或网关的只读工具。

工具描述 v6 可声明 `source_group`。它是应用配置的故障分组标识，只适用于可安全重放的只读工具。适配器用 `source_unavailable` 标识明确的服务级故障。FinScope 将连接失败、连接超时和 HTTP 502 至 504 映射到该类别。参数错误、普通读取超时和 429 保留原分类。

每轮工具结果结算后，Harness 只检查新接受的记录。同组观察都报告服务不可用时增加一轮，同轮有任一成功观察时清除计数。两轮失败后，该组退出本 Run 当前任务版本的候选集合。账本 v6 保留故障轮数及是否耗尽，旧账本按原格式加载。新任务版本可重新尝试数据源。

关闭故障组后，原能力发现策略继续选择可用工具。只有所有未完成的必需项都依赖已关闭的组，且选择结果没有覆盖这些缺口的替代工具时，才认定本轮取证耗尽。还存在矛盾证据或独立必需动作时，沿用原有完成约束。没有可用证据时以明确的源故障终止。有部分可用证据时，模型可提交有限答案，仍经完成策略检查并标记为不可核验。

回归覆盖临时故障恢复、切换独立来源、无证据终止和保留部分证据。FinScope 测试用模拟 HTTP 重放公司、新闻和事件搜索，再用一次重试确认故障。轮数上限以结算轮次计量，同一轮允许多次并发只读调用。该策略不共享跨 Run 的故障状态，适配器声明的分组粒度决定故障影响范围。
