# 失效工作结论的证据重验

状态：已实现为显式实验能力，2026-11-13；尚未通过真实任务收益验收。

## 问题与范围

ADR 0112 已实现显式依赖的版本失效、来源回取和完成拦截，但修改依赖版本即可消除诊断，不能确认结论是否根据当前资料重新判断。本切片仅处理单 Run 活跃工作集内已声明的依赖，不推断漏边，不把模型审查当作事实证明。

## 决策

显式开启 `HarnessConfig.work_recheck`。工作状态以 v3 持久化该要求，旧 v1/v2 和默认策略保持原行为。`propose_work` 的可选重验器在 Runtime 管理的工具调用内执行；确定性归约器只消费已接受的审查收据，回放不调用模型。

当失效结果被改写、换绑、降级或删除，或者失效假设被提升为结果时，构造原笔记、当前直接上游、候选笔记及授权原文区间的材料包。按现有拓扑前沿处理；上游仍失效、缺失或在同一提案改变时不能顺便批准下游。可以先提交新增上游，再在重验中引用；不能静默删除旧依赖。没有变动的失效笔记可以保留，独立分支和普通非结果计划调整不触发审查。

审查读取原文和适用条件，返回仍受支持、修正受支持、应当撤回、证据不足四类判断；协议或依赖失败单独记为未核验。正向判断必须引用材料包中可定位的原文。来源定位只能保证引用存在，不能证明蕴含；最终成果仍由原 CompletionPolicy 验收。审查仅给出有界的外显结论和补证缺口，不采集私有推理。

策略 `work-evidence-recheck/3` 为每个原文区间赋显式零基编号，同时交付各父节点的证据编号组。即使属于同一 Artifact，不同区间也不共用编号。开发回放显示，隐式数组位置会被模型误读为文档编号；修复表示歧义，不放宽原文匹配。正向判断需覆盖每个父证据组。

材料包作为提案的受控附件保存，收据绑定任务、工作集、原笔记版本、完整更新摘要、策略版本和附件身份。归约器核对绑定与接受条件，不能通过删除、改名替换失效节点绕过本次重验。提案保持原有原子接受语义；任一目标未通过则保留旧工作状态，并推进记录消费游标。其他业务工具的成功结果不回滚。

## 预算、失败与兼容

只在有关提案上审查，不逐轮扫描调用模型。一个提案共享工具截止时间，最多六个目标、一次批量模型审查；完整材料和 Schema 通过请求计量准入，容量不足不截掉必要证据后继续批准。原文只能通过 ToolContext 读取，依赖边不能扩大访问权限。取消原样传播，超时或模型故障不能更新工作状态。附件写入后而父提案未接受的孤立附件不构成执行事实。

保持原有六节点和 8 KiB 工作状态上限；详细材料保存在 Artifact。启用策略改变工具和准备策略版本，恢复仍受原配置兼容校验约束。

输出 Schema 新增了可选收据，因此关闭策略时 `propose_work` 的描述版本也由 v5 升为 v6；它仍返回无收据的 v2 提案。不能把旧版本目录缓存或运行配置静默解释为新 Schema。

## 替代方案与验证

直接重绑定保留为朴素基线；全量重算作为成本参照。未采用每轮调用评判模型或自动重生成，因为它们扩大调用成本与误拒面。首先验证来源授权、过期收据、同批竞争、逐层重验、撤回、未知状态、原子接受、取消、重放和旧数据兼容，再运行冻结任务的真实模型对照。测最终答案、陈旧结论、误拒、不必要重做和调用成本；不以确定性测试冒充语义收益。

接入、源码流程、完整失败记录与实验边界见[工作结论的证据重验与实验](../工作结论的证据重验与实验.md)。本轮没有运行全量重算策略，不能报告其成本优劣。
