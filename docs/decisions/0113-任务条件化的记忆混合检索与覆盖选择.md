# 任务条件化的记忆混合检索与覆盖选择

状态：已实现并完成定向实验；显式启用，未替换默认策略。

## 问题与选择

旧链路把所有 ContextDemand 拼成一次 BM25 查询，先按组排名截断；不同子问题会竞争同一 top-k。词法未命中的事实无法被找回，而语义召回即使找到了结果，也可能被上下文编译器的词项评分再次丢弃。

本阶段采用同一授权双时间快照上的逐需求 BM25 + 本地语义向量召回、组级 Reciprocal Rank Fusion，以及带收益递减的需求覆盖选择。保留旧策略作为默认和基线，新策略显式启用。这里不引入向量数据库、自动后台作业或新事实写入策略。

## 机制与不变量

1. SQLite 在一个读事务内固定 scope/head/known_at/valid_at，读取完整可见候选及来源。语义模型只看到这个授权快照；检索期间写入不会改变本轮候选。候选超限显式失败，不把词法 top-k 当作语义候选全集。
2. 每个需求独立查询。词法和向量分数先在完整事实族内取最大成员分数，然后按名次融合；不同通道的原始分值不直接相加。正相似度阈值只是召回门槛，不证明事实适用或正确。
3. 长记忆分块只服务召回，最终交付仍是包含所有条件、争议和来源的完整事实组。禁止静默截断模型输入；局部 embedding 缓存绑定编码器身份、作用域及文本摘要，查询前仍重新做授权和时间筛选。
4. RRF 只产生融合排名，再用名次倒数表示覆盖效用。不能把带大偏置常数、分差很小的 RRF 原始分数当作覆盖强度。选择目标为逐需求加权的饱和覆盖收益；同一需求的重复结果边际收益递减。用实际序列化成本做预算约束，比较密度贪心和最佳单组，并在有界工作量内局部交换。不是任务成功概率，不宣称全局最优。
5. 检索信号通过版本化 ContextSupplyReport 传递给上下文编译器，与当前 demand digest 和 bundle 身份绑定；只增加软分配收益，不改变 Token 上限、记忆权威、来源证明或工具权限。模型正文不能自行设置这个信号。
6. 语义依赖失败可按显式策略退回逐需求词法召回，并记录退化原因；取消不转为降级。总时限覆盖排队、快照、编码和选择。同步本地推理取消后等待当前有界批次结束，不能声称硬抢占。
7. 旧持久化协议保持原样；新供给诊断显式采用 v2。当前策略不自动猜测历史查询时间、不解析任意自然语言条件、不把相似度当成条件蕴含。

## 依赖与验证

新增可选 `local-memory` extra：ONNX Runtime 执行本地编码器，tokenizers 读取对应分词器，NumPy 构造模型输入。它们只承担编码，不接管框架决策。核心包与默认测试不下载模型。模型文件在仓库外显式获取，编码器版本绑定模型/分词器 SHA-256、池化及输入协议；不加载 pickle。

确定性验证覆盖跨表述编码信号、多需求竞争、来源闭包、历史/权限隔离、并发修订、缓存失效、容量、非法向量、超时/取消、回退、最终上下文使用与持久化。冻结小型自然语言检索集，对比拼接 BM25、逐需求 BM25、Dense、Hybrid；报告召回、需求覆盖、无关项和字节成本。小数据集只作为定向检索证据，不等同开放任务成功率。

## 实验结论与限制

同一份 20 条记忆、16 个案例的公开人工语料，事实召回率分别为旧 BM25 55%、逐需求词法 50%、Dense 75%、Hybrid 60%。本地 E5 在当前配置下的三个跨语言案例均未命中，两个负例也全部误召回；不以小规模平均召回提升宣称可靠记忆使用或普遍优于基线。

首轮直接使用 RRF 值作覆盖收益时，Hybrid 只有 50%；改为序位折扣后为 60%。这是根据同一开发集定位机制问题后的复测，不是独立测试集上的泛化提升。没有根据答案修改语料、模型、阈值或逐案例规则；后续仍需要独立语料和端到端任务评测。

默认继续使用原词法路径。新机制的阶段成果是完整授权快照上的可替换召回、真实成本约束的多需求选择，以及从检索到模型可见上下文的可观测链路；语义拒答阈值、可靠重排、跨语言检索和真实任务收益仍未验收。完整实验配置、复现方法与失败案例见[任务条件化记忆检索与覆盖选择](../任务条件化记忆检索与覆盖选择.md)。

## 第一方依据

访问日期：2026-11-07。

- [RRF 原论文](https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf)：按名次融合，避免强行校准不同检索器的原始分数。
- [xQuAD 作者论文](https://ra.ethz.ch/cdstore/www2010/www/p881.pdf)：显式查询方面和多样性选择的设计参照。本实现用现有任务需求作方面，并在字节预算下使用饱和收益，不宣称复现其概率模型。
- [Multilingual E5 技术报告](https://arxiv.org/abs/2402.05672)与[模型说明](https://huggingface.co/intfloat/multilingual-e5-small)：本地跨表述编码候选，遵循 query/passage 前缀和输入长度约束。检索相似度不作为事实真伪判据。
