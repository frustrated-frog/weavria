# 原句约束的记忆联合证据审查

状态：已实现并完成定向真实对照；显式可选，不改变默认启用策略。

## 问题和设计

ADR 0115 的两轮策略在真实验证集中弱于朴素单轮。主要失败是把答案字段扩展成规划前置条件，以及在自由条件键之间生成不存在的边。本轮增加可替换的单轮联合策略，复用原有供给、条件闭包、裁剪降级和会话持久化，不新增第三轮审查。

模型把原问题分成有序原文片段，每个片段属于一个答案项或公共情境。所有片段逐字拼回原问题；每个答案项只对应一个原文片段，名称由宿主从该片段取得，不允许输出额外的规划需求描述。这能阻止文字层面的删题、虚构描述及未分配文本，不能确定性证明语义上的问题覆盖：模型仍可能把一个真正的提问错误标为情境。

宿主根据可见事实的限定生成编号目录，按键、类型和值去重。模型对每个答案项逐条件标记 entails / disjoint / unknown，并指向本题原文片段。条件编号必须真实存在；依据只能来自该答案项或公共情境，不能借用另一答案项的专属情境。unknown 没有肯定前提，不能因为一个字符串写着“未知”就排除所有可能值。

最终协议采用固定长度的成员角色向量与稀疏引文。每个位置绑定快照中的一个成员，Schema 显式给出本批向量长度；direct/conflict 必须恰好各有一条真实引文。只有背景成员使用的条件可省略，直接支持或冲突所需的任一限定仍必须判断。这样减少重复协议工作，不省略事实族审查。

宿主把已定位的题目情境作为合取前提，将有限条件判断翻译为现有条件图的边；同时要求逐答案项覆盖全部事实成员。原有归约器继续决定 supported / missing / conditional / conflict，不接受模型直接写入“充分”结论。条件图前提使用不与任何事实限定同名的内部键，避免意外恒等边。复杂合取的依据作为一个整体前提，不能拆成每条单独蕴含目标的边。

## 不变量和取舍

- 每题最多八个答案项、十六个原文片段。输入、成员与限定目录、答案项乘以审查工作量、完整输出、调用期限均有明确上限。只调用一次，不静默修复、不截断事实族。
- 取消传播；无效分区、无效条件编号、跨答案项借用前提、漏成员、坏引文、超限或依赖错误均不发布部分结论。保留原有失败状态及诊断绑定。
- 所有条件含义仍依赖模型，编号合法和引文存在不证明语义蕴含。模型同时看到材料与问题，可能缩小提问，原文分区只能约束而不能完全消除这一风险。
- 使用 Protocol 允许旧两轮策略和新联合策略复用同一 ContextSource。持久化结果继续使用现有 ContextEvidenceAssessment，联合策略只填写一次调用的 review 摘要，不伪造独立复核。
- 不替代最终回答校验，不开启自动补搜，不将实验成本隐入主模型用量指标。

## 验证与阶段结束条件

保持旧开发集和旧验证集不变，用同一模型配置比较朴素单轮、旧两轮、新联合。另行在首次执行前冻结不同事实的验证集；不依据其结果调整策略后仍称作独立验证。记录完整状态、答案项的支持/缺口、非法协议比例、延迟和调用数。端到端契约需验证新策略通过原有供给进入主模型，预算淘汰后正确降级，Session 重开后保留诊断。

完成定义是可替换策略接线、确定性不变量、真实对照及失败结论齐全；只有真实证据支持时才谈策略收益，不用测试数量替代语义质量。即使小型对照改善，也不直接开启全局默认。

## 本轮结果与限制

2026-11-09，固定 `deepseek-flash` 配置，同次最终对照中，开发集/旧验证回归/新增验证集的联合策略分别为 13/13、9/9、10/10；原两轮为 9/13、6/9、6/10；朴素单轮为 12/13、9/9、10/10。联合策略每题一次调用，平均约 1.4 秒，两轮约 3.5 秒。没有据此声称通用错误率为零，或已改善最终回答质量。

保留了开发过程的负面证据：逐成员对象导致多问句漏成员；全量条件表导致无关条件漏填；明确动作包络之前出现过 HTTP 200 但模型输出无法归一化。这些失败均扣留而非放行，也没有按失败案例增加专用词表或隐式重试。

新增验证集在 v2 首次执行前冻结，初次结果联合 10/10、单轮 10/10、两轮 7/10。后续依据开发/旧回归失败修改了输出矩阵和动作包络，因此最终 v3 对这十题的 10/10 是复测，不能冒充全新盲测。保留每阶段结果和边界，详见[记忆联合审查的实现与对照实验](../记忆联合审查的实现与对照实验.md)。
