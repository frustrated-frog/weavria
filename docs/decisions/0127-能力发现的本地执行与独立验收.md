# 能力发现的本地执行与独立验收

日期：2026-11-14。状态：已实现，完成初始与时效性适配后两次完整对照。结果与限制见[实现和验证](../能力发现的本地执行与独立验收.md)。

## 问题与边界

ADR 0126 的实验只到任务准备：正确选择能力不保证参数、调用依赖、结果或安全停止正确。本步建设可重复的本地执行实验，将发现接入已有 AgentHarness、Session、Runtime、Tool 和 Artifact 链路，不引入新的核心执行器或将测试答案变成 Completion Policy。

任务覆盖完整文件字节指纹、文件属性、归档正文与修订差异、标识符查找后再计算指纹、重叠日历事件的空闲区间，以及能力缺失和无需工具。所有工具实际读取独立临时目录中的公开合成数据；目录中的干扰能力也有可执行实现。目录、任务、期望答案和证据规则在真实模型运行前冻结。

## 独立判定

只将任务原文交给模型。工具闭包只持有环境数据，不持有任务 ID、标准答案或预编排调用序列。模型自行选择工具、参数、批次和结束时机。

执行结束后，离线判定同时要求：正确的最终 JSON、成功 Run、已接受 ToolRecorded 中对应对象的成功操作。预期答案保存在单独任务清单中；判定器不调用工具函数计算答案。多步查找要求先获取对象位置再读取该位置。日历任务允许两种证据路径：直接查空闲区间，或读取覆盖请求窗口的忙碌区间后计算；不把唯一工具名当作成功。

分别报告答案正确、证据满足、任务成功、能力不足停止、无关调用和失败类别。明确的 NO_PROGRESS 是安全保留结果，不等于交付成功；网络异常、协议错误和预算耗尽不能记作正确拒绝。没有必需能力时，即使模型说完成，也不通过独立验收。评测结果不回流当前 Run，不引导模型修正成标准答案。

## 执行与隔离

每个任务/策略使用新的临时环境和 SQLite Session，关闭后删除。模型只使用规范化虚拟绝对路径，工具仅能访问清单内文件；拒绝路径穿越、符号链接、特殊文件和超限读取。文件很小，使用有大小上限的同步本地读取，不创建脱离父请求的后台任务。异步入口提供取消点，Runtime 继续负责超时、授权、参数验证、结果归档与清理。

本地环境没有写、删除或发信工具。缺失能力任务用于观察错误替代与安全停止，不制造真实副作用。实验不声称提供面向并发恶意宿主的通用文件沙箱。

## 执行反馈推动的接入修正

首轮执行发现：模型声明 current 证据需求后，默认结构提取器保留 `$freshness` 缺口；即使字段与答案正确，也不能通过完成检查。保留完整首轮结果，不修改通用提取器或降低任务要求。

本地适配器通过既有 HarnessEvidence.extractors 接口提供 LocalSnapshotEvidence：本次 Run 内工具直接读取当前本地快照，没有缓存或写能力；只对绑定目录、工具版本、授权成功记录和匹配 Artifact 提供有效时效性判断。字段检查、结果类型和 structural 证明强度保持，原需求的 current 不被重写。这个承诺不推广到任意外部工具，不声称语义正确或答案已验证。

保留 `--evidence-mode structural` 用于重现原组合，默认 local_snapshot 接通本地读取语义。修正后使用相同任务、环境、目录、模型和预算重新比较；原始失败不删除或回填。输出 v2 增加证据模式、完成检查原因与 Need 缺口，避免以后仅看到 completion_rejected 而无法定位。

## 对照与成本

混合发现、只检查、检查加两轮补搜使用同一 Harness 装配和执行设置，只改变发现配置。朴素基线在每次执行请求直接暴露完整工具目录，关闭任务理解；它用于比较整套 Harness 的成本与结果，不是仅改变召回策略的消融组。

冻结模型、温度、窗口、请求字节、调用和时间上限，轮换策略顺序。记录数据/目录/源码摘要、索引版本、真实 usage、发现报告、终态、工具参数与成功状态；不记录供应商凭据或私有推理。每行结束立即保存，已存在输出不可覆盖；取消也保存已完成工作。原始输出位于忽略目录，书面报告保留失败和费用/延迟取舍。

## 验证与限制

确定性测试验证真实文件计算、区间边界、参数与路径拒绝、取消和环境清理，以及判定器拒绝猜中答案、错对象、失败调用、缺失前置依赖和泛化异常。Fake 端到端测试只验证链路。真实模型对照检验完整任务表现，不用测试数量证明能力收益。

这仍是有限公开合成任务，包含模板化干扰工具，不能代表企业真实目录、长会话、动态权限和开放网页任务。没有为本步增加执行中主动再发现、语义完成审计或长期自适应；如果实验暴露这些缺口，先保留失败证据再设计下一步。
