# 原句锚定的记忆查询扩展

状态：已实现并完成真实模型定向对照；显式可选，默认关闭。

## 问题和设计

ADR 0117 的负反馈残差查询无法跨越“who signs off”与“approver”之间的词汇差异。本轮只在 missing 存在时增加一次批量语义扩展，不改写原任务，不让扩展文本进入记忆或成为证据。

模型只接收原问题、缺失项和残差查询，不接收完整语料或隐藏答案。每个缺失项最多返回三个检索别称、一个原句焦点引文以及需要保留的实体/条件引文。宿主检查缺失项身份、原句定位、词组和整体长度，保留原残差查询作为主视图前缀，只追加原文锚点；别称进入独立词法视图。两路分别 BM25 排名，再按原词法/别称 1:2 的固定权重做归一化秩融合，Hybrid 的 Dense 通道权重为 1。没有别称命中时不稀释原排名。融合后使用名次倒数作为选择效用，共享现有候选/字节/事实族名额上限。超过上限整体回退残差，不截掉尾部条件。原问题始终完整交给候选重审器。

这不能确定性证明同义表达正确或所有实体条件都被模型识别。原文引文只是可定位的低信任语义提案，召回仍是软排名。真正的接纳继续依赖同一授权快照、完整原问题重审、已有证据闭包保护和缺口单调改善。错误别称可能导致漏召回或错误排名，必须在实验中计入。

## 替代方案与研究依据

2026-11-11 核查的第一方材料：

- [Query Rewriting for Retrieval-Augmented Large Language Models，v3](https://arxiv.org/abs/2305.14283v3)：把查询改写作为检索—阅读链路中的独立环节；论文还训练重写器，本轮没有训练或复现其 RL 部分。
- [Query2doc，v2](https://arxiv.org/abs/2303.07678v2)：用生成的伪文档扩展查询。本轮仅借鉴检索扩展思想，选择短词组与原文锚点，减少生成具体答案的空间，不声称复现论文结果。

已有 Dense/Hybrid 检索也可解决同义匹配，但需要编码器及其索引/成本前提。扩大首轮候选更简单，本轮将其作为对照，避免把多一次模型调用的收益夸大成查询扩展必然更优。当前只有同一需求的两个词法视图，没有任意多查询并行、训练重写器或无限反馈循环。纯 Dense 配置不能启用此词法扩展，构造时明确拒绝。

## 失败、预算与版本

查询扩展有独立、显式的期限和输入字节上限，最多一个模型调用；失败退回原残差查询，取消原样传播。原 refinement 期限仍覆盖追加选择和重审，Session 总期限覆盖全部工作。初次已支持、条件未知、争议或审查失败时不支付扩展成本。

ContextRefinementReport 新增 v2 和可选 ContextQueryExpansion，记录扩展策略、输入/提案/输出摘要、调用尝试数及失败分类。v1 序列化不增加字段。成功扩展输出摘要必须等于最终追加选择的查询摘要。最终证据仍来自候选审查，不读取扩展内容。外层 ContextSupplyReport 沿用 v5，其嵌套报告有自己的版本。

## 验收

验证原句锚点、身份、长度和失败降级，检查取消/超时清理及会话重开；旧残差策略与新扩展使用相同候选名额、事实族闭包、模型配置及重审门槛，另比较增加首轮候选。真实模型评估最终答案、错误非空答案、引文定位、调用及延迟。开发失败不删；新冻结集首次结果与复测分开陈述。

## 本轮结果

第一版直接拼接锚点和别称导致背景词再次占优，旧四题从残差 3/4 退化到扩展 1/4；八题新集首次也没有改善。这个负面证据促成双通道融合，原八题在后续结果中明确标记为回归集。最终 v2：旧四题两策略均 3/4，八题回归为 3/8 → 6/8，另行冻结的四题首次验证为 2/4 → 4/4。扩大首轮名额为两个的对应结果为 3/4、4/8、2/4。

仍未解决的旧 sign-off 案例：模型产生 approves / authorizes / approval authority，没有生成能命中语料的 approver。未添加该题专用规则。固定 1:2 权重不是经大规模调优证明的最优值，两个小数据集的改善也不足以证明长任务收益。详见[原句锚定查询扩展的实现与实验](../原句锚定查询扩展的实现与实验.md)。
