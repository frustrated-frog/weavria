# 0074 记忆命题的竞争解释与语义修复

状态：实验实现，显式启用；当前实验未观察到自然语言收益，不晋升为默认策略，2026-11-01。

## 问题

先前形成管线只有一份平坦提取，错误的角色附着、条件遗漏或命题拆分进入后续阶段后只能被拒绝。增加一个判断字段不能恢复原来的意义。本轮建立实际生成、比较和替换解释的局部搜索，研究命题形成而不是扩大写入拒绝规则。

## 机制

保留现有提取器作为初始候选。独立分析调用只读取原文，不接收初始提取，生成固定的含义单元；每个单元是一个连同角色、适用条件和时间的可记忆意义，具有焦点来源引用。单元由模型从原文生成，不由宿主或评测标签预先标注。

修复器读取原文、固定单元与当前解释，生成一至两个完整重建方案，可以合并被拆开的关系、拆分真正独立的事实、修正条件附着。对所有候选执行相同 grounding，再在一次对照调用中评估当前解释与重建方案：每个固定单元的 distorted/missing/partial/faithful 等级，以及无来源主张数。每个 assessment 将等级与主要缺陷绑定在一起，不使用两条平行数组。比较过程中不允许重定义单元，候选 text 和引用也不进入结构评分视图。第二轮会收到前轮失败方案和缺陷反馈。

宿主执行支配保持的局部搜索：只有逐单元不退化、无来源主张不增加、且至少一个维度改善的候选可替换当前解释；多个可用候选优先覆盖等级总和，再选更少的无来源主张与更紧凑的解释，最终使用内容指纹稳定打破同分。保留同次比较结果、全部已比较方案和选择。相同解释去重，重复生成保留调用收据；最多两轮、每轮两个候选。首轮总会生成替代方案，不凭初值自评提前结束；竞争比较后完全 faithful 且无无来源主张时可停止后续轮次。

这套顺序只针对模型判断定义，不能证明语义真伪，也不是概率置信度。distorted 低于 missing：不再主张错误事实可以算改善，但遗漏仍明确记录，不能称任务完整。已有正确单元不能通过丢弃而换来更好成绩。

## 接入与失败语义

新增 ModelMemoryRepairingExtractor 包装已有 MemoryExtractor，公开端口不变。完成的 MemoryExtraction v4 包含选中结果与搜索记录，随后沿用关系解释、条件闭包、时态事实集和事务提交。旧 v1–v3 序列化保持不变，原模式默认不启用。管线版本绑定修复策略、模型和初始提取器版本。

一次提取的全部搜索共享父期限，取消不转为普通失败；协议失败不会偷偷采用未经比较的候选。搜索结果完成后由现有形成作业持久化，CAS 重评复用选中解释。当前不持久化提取阶段中途状态，因此阶段内取消后重试会重新提取与搜索，不能宣称跨崩溃复用每次模型调用。

## 取舍与验证

没有采用不断重新生成后取最后一次、宿主领域词典或仅提高通过率的评分。选择显式的源含义覆盖和候选支配规则，因为它能阻止改善某个局部却破坏其余事实；代价是不能跨越必须暂时退步的搜索路径，且含义单元和语义评分仍可能错。

确定性测试验证非贪婪取最后方案、局部退化回滚、同分稳定、去重、期限、取消、旧 Schema 和作业重放。真实模型比较相同原文上的原提取与搜索结果，并记录成本；独立验证材料不用于本轮调提示。算法与模型评分器的效果分开报告，不宣称通用语义理解已解决。

开发重放暴露了两项设计问题并已修正：平行等级/缺陷数组会失配；可见初值的分析器会复述错误拆分，再以完整自评提前结束。最终采用原文独立分析与先探索、后比较。第一轮验证失败保留，修复后重跑已看过的数据按回归报告，不能再称独立盲测。完整运行、限制与源码讲解见[记忆命题的竞争解释与语义修复](../记忆命题的竞争解释与语义修复.md)。
