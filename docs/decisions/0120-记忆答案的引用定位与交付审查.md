# 记忆答案的引用定位与交付审查

状态：已实现为显式可选的 Harness 能力；未自动接管 Runtime 最终交付。真实文档实验尚未证明增加审查能稳定提升回答收益。

## 问题

ADR 0119 改善了部分候选召回，但“找到标注段落”“材料足够”“答案正确”“引用支持答案”是四个不同判断。模型可能引用真实句子却把否定翻转，也可能答对核心事实却附加不受引用支持的建议。仅检查引文是原文子串无法拦住这些错误。

本切片把现有 `MemoryContextSource` 和证据报告接到可审查的答案生成，不引入新的检索器、需求账本、会话状态机或后台重试。它回答的是：在已经交付的完整事实族上，如何生成、定位并复核一个有界答案；不承担通用 Agent 的全部任务完成判定。

## 决策

新增公开 `ModelMemoryAnswerer`。`propose` 返回明确未获准的 `MemoryAnswerDraft`，用于朴素基线和宿主检查；应用使用 `answer`，仅在原问题的每个需求均被现有证据审查支持时生成。

执行流程为：重新校验供给与原需求摘要 → 检查证据状态 → 发送完整获准事实族 → 模型提出有限声明及成员序号、引文 → 宿主定位原文并绑定来源 → 单独调用复核器 → 根据结构化判断计算交付状态。复核器可以配置另一 Provider 及独立配置身份；默认是同一 Provider 的另一次无共享对话调用，不声称统计独立。

声明最多 12 条，每条最多 4 个引文。`MemoryAnswerCitation` 记录 bundle、成员、revision、source IDs、原文字符起点和原始切片。模型不负责复制来源身份。复核器分别返回每条声明的 `entailed/unsupported/contradicted`、每个引文是否实际提供支持、答案是否覆盖完整问题。宿主要求索引无遗漏、无重复，维度与草稿完全一致。

只在所有声明受引用支持、所有引用相关、问题完整覆盖时发布答案。结果绑定需求、供给、证据、草稿和复核摘要，并保留逐条关系与引用支持向量。拒绝结果不携带可被误用为最终答案的草稿。摘要是审计身份，不是语义证明；模型仍可能错误地接受或拒绝。

## 引文表示修复

开发集显示，模型会把源文中的换行复制为空格，或在已经解析的 JSON 字符串里再次输出字面量 `\n`。这使真实支持材料因表示差异被拒绝。

共用的 `locate_memory_quote` 优先接受唯一精确匹配；失败后仅尝试空白折叠及一层 `\n/\r/\t` 控制字符还原，要求唯一来源区间。返回值始终是**源文原始切片**，保留换行与缩进；不接受大小写变化、标点替换、补词、删词或翻译。多个候选区间必须拒绝。原文本来包含字面量反斜线时，精确匹配优先。

位置修复不能证明含义相同，尤其代码缩进可能有语义。后续复核读取恢复后的原文。证据归约也使用恢复后的原文 SHA；已有精确引文可以在源文中出现多次的契约保持不变，新增答案引用则要求唯一定位。没有泛化为模糊相似度门槛或放宽语义接纳标准。

## 状态、失败与资源约束

| 状态 | 含义 | 是否发布答案 |
| --- | --- | --- |
| `accepted` | 现有证据支持，且完整草稿通过逐条复核 | 是 |
| `abstained` | 材料缺失、条件未确定、冲突，或生成器主动不答 | 否 |
| `rejected` | 草稿未通过支持性或完整性复核 | 否 |
| `unverified` | 未审查、协议错误、容量不足或模型不可用 | 否 |

调用者传入不同原问题、损坏的供给绑定属于输入错误，抛出异常，不伪装成合理拒答。模型协议、引文和复核错误保留失败类别；取消原样传播。生成与复核共用一个截止期限，不自动重试，不产生无人管理的后台任务。

默认最多 128 个成员、128 KiB 序列化业务输入、120 秒两轮调用期限。复核容量包含新增草稿，不能只检查检索材料后再无限增加答案。超限不静默截断事实族。业务输入字节预算不等于 Provider Token 预算，模型调用仍受现有 Provider 配置约束。

## 版本与替代方案

答案类型采用新 Schema v1，策略身份 `memory-answer/2` 绑定生成器与复核器配置、策略和提示。联合证据策略升为 `joint-memory-evidence/4`，两轮证据策略升为 `memory-evidence/3`，使引文定位行为变化具有可见身份。没有更改既有持久化 Schema 或迁移历史报告。

未选择只做子串校验，因为它不能验证语义；未让生成器在同一次输出中批准自己，因为错误与自信容易一起复制；未加入无界反思或重生成，因为本轮先量化独立复核的收益和误拒成本。单独调用仍可能共享模型偏差，真实实验必须保留无审查基线。

## 验证与依据

确定性测试验证来源身份、否定翻转的拒绝执行、维度错误、输入绑定、预算、取消与超时清理。Fake 指定的语义判定只能验证状态和契约。真实实验冻结完整文档、问题和评分要点，分别记录答案正确、引用支持、拒答、模型失败及成本；不把模型失败算作正确拒答。
