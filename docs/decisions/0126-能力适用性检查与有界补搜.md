# 能力适用性检查与有界补搜

日期：2026-11-14。状态：已实现，完成原冻结任务与新协议任务集对照，默认关闭。详见[实现与验证](../能力适用性检查与补搜的实现和验证.md)。

## 具体问题

ADR 0125 的文件指纹题稳定暴露了两层错误：正确工具在召回时丢失，任务解释器又把归档读取当作计算指纹的替代。提高 top-k 不能解决“候选存在却不适用”，空提名也不能区分直接回答和能力缺失。本阶段建设显式的适用性反馈与补搜闭环，不改 Runtime 授权或把检索相关性当成证据。

## 流程与职责

原有卡片召回、提名、合并保持不变。显式开启 fit 后，提名工具展开完整描述符和 Schema，检查模型必须逐个作出 supported、operation_mismatch、input_mismatch、output_mismatch 或 uncertain 判断。所有判断绑定当前目标/显式约束的逐字引用；supported 还必须引用工具说明或 Schema 字符串叶子。宿主验证身份、分区完整性、引用存在与作用域，禁止伪造字段或凭主题相关就授予执行权。引用存在只是可核验的根据，语义蕴含仍由模型判断，不宣称形式化正确性。

检查返回三个互斥状态：ready（至少一个支持项且无缺口）、no_tools（无需工具，不得保留支持项或缺口）、search（至少一个有请求原文锚点的缺口和补搜查询）。缺少运行参数应留给现有澄清机制；动作、输入对象类型或输出不匹配才是能力问题。

search 时保留当前 supported 集合，对每个缺口查询同一授权目录，排除已检查卡片，再提名新工具。下一次检查重新比较“保留支持项 + 新提名”，既保护多动作请求中已找到的能力，也允许撤销此前误判。查询只改变召回，不改变原始任务；每次检查仍看到完整原请求。没有后台任务、自动执行或隐式扩大权限。

## 状态与终止

每次 discover 的局部状态包含：已检查卡片集合、保留支持项、完整协议展开集合、检索报告、适用性检查报告和共享模型调用账本。每轮新增卡片必须与之前不相交。排名截断之前排除旧身份，避免旧 top-k 占满补搜窗口；索引仍绑定完整授权目录，IDF 和向量缓存不因排除项而重建。

默认最多两轮补搜、每轮最多两个查询、一次检查最多 24 个完整协议。所有阶段共用已有 max_calls、max_input_tokens 和准备期限；没有为每轮重置预算。每次发送前记录请求摘要、实际 Token/字节；格式错误不自动重试，也不消耗补搜次数来伪装修复模型协议。

ready/no_tools 才发布最终候选。达到补搜轮次、全目录已检查或没有新卡片而仍有缺口，返回 NO_PROGRESS 与稳定原因码，失败报告保留已完成过程但不发布部分工具。Token/调用/协议展开容量不足仍是 CONTEXT_BUDGET_EXCEEDED。超时、取消和编码器故障保持原分类和清理语义。目录在发现中变更仍由 TaskUnderstandingEngine 拒绝。

已看过但未被卡片模型提名的工具不在本轮重复审查，这可能保留卡片筛选的假阴性；有界补搜不能保证穷尽语义搜索。上下文任务仍先全扫描，再检查完整候选；若此时仍有缺口，不靠脱离上下文的查询继续搜索。

## 契约与集成

CapabilityDiscoveryConfig 新增可选 CapabilityFitConfig，默认关闭。未启用时保持原配置摘要与请求内容。索引 retrieve 新增 exclude_names；无排除时仍返回报告 v1，有排除时返回 v2 并记录排除身份。发现报告 v3 保存补搜检索与检查报告，旧 v1/v2 序列化保持；理解记录携带新报告时使用 v4。正式 Session/Runtime Schema 不变，reporter 仍是显式归档入口。

检查报告只存身份、判断码和引用/查询摘要，不存请求正文、工具正文或私有推理。查询、引用是短暂的数据，用后丢弃。报告可回答检查了什么、为什么补搜、是否有进展、成本多少，不能作为任务完成事实。

## 取舍与验证

不直接复用 RequirementCoverageAssessment：它验证已形成的任务规格，本机制位于规格形成之前，处理的是能力是否实现请求动作；两者不共享已满足状态。也不增加与用户请求无关的规划器或手写同义词表。当前采用可替换的真实模型检查，宿主承担状态推进、原文/协议引用验证、权限边界、去重与预算。

确定性测试覆盖误选拒绝、补搜恢复、部分支持保留、多查询去重、排除前置、停滞/轮次停止、引用与身份越界、空候选、总预算、取消、目录变化及报告兼容。真实实验包含上一轮冻结任务，以及另行冻结的不同输入输出 Schema、近义但动作不同、需要多个工具和目录无对应能力的任务。比较原混合扫描、只检查不补搜、检查加补搜和完整目录，记录正确选择/安全停止/误接受、召回恢复、失败与真实成本。不能用一题修复宣称通用提升。
