# 0032 有预算的主动上下文恢复

## 状态与问题

已实现，2026-10-23，基线 `45f819b`。本切片只恢复当前 Run 已接受成果中的原文，补足 ADR 0030 的完全省略来源无法直接回读的边界。历史检索继续沿用 ADR 0031，不扩展为 Memory。

## 机制

新增独立 `recover_context` 模型决策，支持按自然语言查询发现片段，或用当前 Run 的调用身份、来源摘要和区间精确恢复。它与工具批次、Finish 互斥。Runtime 的模型控制回合负责接受恢复意图；Context 负责有界搜索、精确区间、预算分配与可读视图重建。恢复原文是上下文投影，不伪造 ToolRecorded，也不重复调用原工具。

恢复先从当前 Run 权威记录验证来源；只以模型提供的 ID 或工具参数不能扩大访问集合。查询按词项覆盖选择互补片段，精确请求按来源地址读取；对已恢复区间做集合差，避免重复恢复同一段内容。限定请求轮数、单次范围数、单次及累计编码字节和索引/评分工作量。无命中、重复、无效来源、预算不足与额度耗尽分别反馈。

每次成功恢复先在完整请求中预演：被恢复区间成为指定来源的最低可行表示，必要祖先仍至少保留引用，其余内容参与既有有界分配；完整 Session 请求仍复核 BPE、字节和控制回执预留。接受恢复结果后，下一次 ContextSelected 必须绑定同一恢复集合。只有新的上下文被接受并开始模型调用后，普通工具才能通过既有 EvidenceAccessView 读取这些来源。

恢复区间有限期保留，直到同一任务修订下的一次模型响应被接受。保留期间不能降级为纯引用；响应接受后重新参与正常选择。用户修订使旧保留失效；正在进行的恢复必须结算为过时结果，不能让旧需求污染新修订。恢复读取和编译全过程属于父 Run 生命周期，取消必须向上传播。

开启预算内收尾时，恢复准备还必须遵守探索子期限。探索超时、迟到候选和原恢复动作的结算由
[ADR 0061](0061-主动恢复的探索期限与完整结算.md) 补齐；本初始版本只受父期限约束。

## 协议与职责

新能力显式启用。新增模型回合 v2、控制请求/事件 v4，以及独立版本的恢复结果与诊断；默认路径维持原有版本和序列化。Core 记录身份、配置、范围、额度和事件；Runtime 归约恢复请求、保留期限及去重账本；Context 访问不可变成果，执行搜索和表示分配；Session 持久化请求及报告。供应商协议明确只在启用时接受恢复动作。

恢复不修改普通工具的 Policy，不把来源可见性当成外部工具授权，不扩大已经准入或正在执行的批次。恢复动作的失败是控制反馈，不能伪装成工具成功；真正存储/框架故障仍终止运行并保留错误原因。

## 取舍

- 直接放开所有历史成果读取会破坏最低回执预留，不采用。
- 从任意工具参数猜测依赖并扩大权限没有稳定语义，不采用。
- 使用独立恢复决策，让意图、预算、接受事实和消费期限明确；代价是增加模型轮次和版本演进。
- 首轮复用已验证的词项索引和覆盖策略，不宣称语义检索。结果源自原始成果，不使用模型生成的摘要。

## 验证

契约与故障注入覆盖来源身份、权限、原文区间、预算拒绝、去重、有限期保留、任务修订、取消、提交失败和事件回放。冻结真实资料与任务，比较被动上下文、普通回读、受控恢复；正确答案和来源标签只进入评测器。Fake 验证控制机制；真实模型效果需要显式启用的固定配置评测，未运行或无收益都如实记录。

## 已验证的结果与边界

新增恢复结果由 `TurnDecided → RecoveryResolved` 表达，不复用只表示工具派发和完成候选的 `TurnResolution`。RunStarted v2 保存恢复配置，ContextSelected v2 绑定保留集合摘要，ContextCompilation v4 保存精确范围；ControlRequest/ControlEvent v4 显式启用。SessionRequest 外层 v5、SessionEvent 外层 v4 和 SQLite v6 不改结构；内部类型独立版本化。旧协议拒绝新恢复动作，旧序列化省略新增字段。

恢复准入前检查完整 Session 请求的 BPE、字节、控制回执预留和依赖闭包。每次实际发送前再次校验保留内容。SQLite 接受恢复事件时，从已接受成果验证原文摘要与范围；提交请求时验证其可读视图，不能仅凭报告宣称恢复成功。JSON Pointer 的纯寻址操作移入 artifacts 公开边界，tools 保留原导入入口。

冻结基线提交的四份真实源文件与六个信息缺口查询，12 个评分片段：被动上下文送达 2，乐观的可见来源回读送达 6，主动恢复送达 7。末次请求输入 Token 总计分别为 11423、17063、15195。见 [主动上下文恢复与预算闭环](../主动上下文恢复与预算闭环.md) 的复现条件、失效案例及完整局限。这些数字只证明原文交付，未运行真实模型，不能证明自主缺口识别、查询生成或任务成功率。
