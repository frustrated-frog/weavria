# 记忆候选重排与无答案校准拒绝

状态：已实现并完成本地定向实验；显式启用，默认不变。

## 问题和机制

ADR 0113 的排名和覆盖值不能表达绝对相关性，两个无答案案例均误召回。固定提高 Dense 阈值会同时损失改写和跨语言召回。本阶段增加显式可选的第二阶段：交叉编码器联合读取需求和完整事实组，重新排序；独立无答案查询上的最高候选分数用于校准拒绝。

拒绝采用保守的经验尾概率：`p(s)=(1+#{null_max >= s})/(n+1)`，仅当 `p(s)<=alpha` 才接受该组进入上下文候选。使用每个无答案查询的候选最大值，避免把同一查询内多个候选误当独立样本。相等分数保守拒绝；样本不足时最小 p 值也不能通过。保留分数分布和完整流水线摘要，绑定模型、输入表示、候选策略和可见语料；不得跨这些边界复用校准。

这是 split-conformal 秩校准思想的有界应用，不是复制某篇论文的全部算法。若无答案校准查询与未来无答案查询可交换，且流水线固定，可讨论无答案查询上误接受任一候选的边际控制。当前手写定向数据不能证明这些假设；该规则不保证有答案查询的候选精度，不证明条件蕴含，也不处理事实真伪。

## 执行和失败语义

- 第一阶段仍先授权和固定双时间快照。第二阶段只读取其候选，不能扩大权限或恢复已撤回事实。
- `population_digest` 绑定可见版本、来源和作用域，排除不改变候选集合的查询时钟。记忆增删、修订、过期或权限作用域改变后，旧校准显式失效；当前宿主须重新校准，不自动在后台更新。
- 以完整事实组构造交叉输入，保留主体、属性、所有成员文本、限定、有效时间及争议状态。不裁剪例外。超出模型输入容量时标记无法评估并停止供给该关联，而不是截断后给出高分。
- 候选数和配对数有独立上限，未经评估的关联不能绕过门槛。一个组对任一需求通过即可保留整个组，跨需求的拒绝不会删除其他需求已接受的关联。
- 分数仅用于重排和拒绝；覆盖选择继续使用名次折扣。排名本身不形成权威记忆或工具许可。
- 编码器版本变化、非法输出和配置绑定不一致都显式处理。故障策略可选择失败或全部扣留；不自动退回未经验证的候选。取消继续传播并回收已拥有工作。
- 供给诊断升级为 v3，v1/v2 保持原序列化。记录每个需求的候选、已评估、接受、最高分、校准身份和省略数量；报告也计入完整字节预算，并随 Session 事件持久化。

## 替代方案与边界

不选择基于答案词表的规则、不对每个案例设阈值、不把生成模型自报置信度当校准。本地交叉编码模型能减少生成调用成本并提供稳定输入输出，但对复杂否定和条件推理没有可靠保证。本阶段的“适用性”限定为是否值得作为候选材料供给；自然语言条件是否被当前情境满足仍未实现。

验证使用原失败集作回归、新语料的独立校准/评估查询作定向对照，先冻结后运行。对比原 Hybrid、仅重排、重排加拒绝，报告召回、误接受、负例不召回、未知与延迟，保留失败。默认路径不变。

## 结果和取舍

新语料 20 个评估请求中，事实召回由 70.6% 提升至 94.1%，无关事实由 16 降至 3，8 个无答案请求有 6 个不再收到记忆。旧语料 16 个请求经同语料重新校准后，事实召回由 60% 提升至 85%，两个无答案请求均无供给。两个语料均使用另行冻结的 32 条无答案查询校准，评估标签不用于选阈值。

首轮跨语料直接使用新语料的校准时，旧语料召回仅为 60%，明显弱于仅重排的 85%。据此补上可见语料绑定，最终实现不再允许这种复用。代价是当前更适合固定或稳定的记忆集合；持续增量记忆如何低成本维护校准仍未解决。

这些是手工小型检索集上的定向证据，alpha 为每需求的名义拒绝参数，不是多需求整轮可靠率。有答案请求中仍可能选错记忆，无答案请求仍有两个假阳性；没有验证最终生成答案的正确拒答。详见[记忆重排与校准拒绝的实现和实验](../记忆重排与校准拒绝的实现和实验.md)。

## 第一方依据

访问日期：2026-11-07。

- [Sentence Transformers 多语言交叉编码模型](https://huggingface.co/cross-encoder/mmarco-mMiniLMv2-L12-H384-v1)：按 query/passage 成对输入产生标量，选择固定 revision 的本地 ONNX 文件；不引入外部 Agent Runtime。
- [Towards Trustworthy Reranking](https://arxiv.org/abs/2402.12997)：重排的拒绝行为应单独建模和评估，排名改善不等于可靠供给。
- [Conformal Prediction 教程](https://arxiv.org/abs/2107.07511)：有限样本秩校准和可交换性条件。本实现使用无答案查询最大值的单侧尾概率；没有宣称在分布漂移或任意条件推理上的保证。
