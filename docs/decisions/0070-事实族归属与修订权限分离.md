# 0070 事实族归属与修订权限分离

状态：已实现，显式启用；真实验证未达到成熟验收，2026-11-01。

## 问题与选择

自然形成实验发现同一属性被命名为“默认语言”和 `document_language`，导致完整组召回失效。既有 alignment 要求条件相同，因为它授权 reinforce/contest/supersede；放宽这个检查会让例外覆盖一般规则。

本切片增加独立的同族归属提案，不扩大修订权限。复用已接受事实的 `(scope, kind, subject, predicate)` 作为规范族键，而不是新增一套可变族表。稳定性来自入库前规范化；原提取、对齐锚点、引用和准入决定都保存于形成日志。

## 协议与执行

- `MemoryReview` v3 增加 `families`，每个候选至多一个 `MemoryFamilyAlignment`。只能绑定 `relation=new`，不能和目标修订混用。v1/v2 序列化不包含新字段；旧记录可读取，旧程序不能读取 v3。
- 同族提案绑定候选索引、已接受目标 ID/版本，以及 subject 和 predicate 的两项来源对应。引用必须逐字落在焦点用户原文中，也必须属于候选已引用来源。引用落地不能证明语义蕴含；独立 reviewer 的判断仍是可错的模型解释。
- 宿主只复用锚点的 subject/predicate；候选 value、qualifiers、text、有效区间和 source_ids 均不更改。模型必须确认谓词中的限定已经显式保留于 qualifiers，否则应返回 unresolved。
- 宿主先执行现有来源、作用域、保留策略和语义复核检查，再验证同族归属，最后执行原有重叠与批次碰撞检查。同族后同条件重叠的新事实不能绕过冲突/修订路径。
- 仅引用本次完整、有界 reconciliation 中的当前 semantic 断言；不能跨作用域、引用退役版本或引用同批未接受候选。失效引用生成 `unsafe_family_alignment` 待定决定。一般规则和例外的适用关系保留在原条件中，不由宿主猜测条件蕴含或优先级。
- 形成计划、记忆 mutation、消费游标仍沿用已有持久化及原子接受机制。head CAS 失败后重取快照、重新复核，复用已经落地的提取；不能把旧族锚点带入新快照直接提交。取消只保护实际事务结算，不保护任意模型调用。

`ConservativeMemoryAdmission` 升至 v3，流水线版本随之改变；未完成的旧流水线必须用原版本恢复，不能静默改换策略。`ModelMemoryReviewer(family_alignment=True)` 显式启用 v3；默认 v2 协议留作基线（适配器版本 2.1，显式记录提示和可见 Schema 已变化）。断言、事件及 SQLite DDL 不变，已有事实不会被后台重分组。

## 一次请求如何流转

“本项目文档使用中文”形成规范属性；后续“README 长期例外使用英文”可能提取为另一种谓词。reviewer 既判断该陈述可保留，也提出同族锚点。宿主验证后仅规范化属性名称，新增独立条件断言。`recall_groups` 因两者共享规范族键，将它们整体参与 Context 选择；不能只切掉例外。每次发送仍绑定来源快照与实际交付摘要。

## 替代方案与边界

1. 增大 k 或添加向量检索只能增加命中概率，不能建立闭包语义。
2. 全局谓词字典需要事先规定领域，不适合此阶段的自由陈述；当前只从本作用域已接受事实借用族键。
3. 显式族 ID 和关系图可支持既有族合并、拆分与历史关系查询，但需要新的持久关系、双时间迁移和循环处理；当前没有必要为本例引入这些能力。
4. 不允许 `families` 任意改写条件来提高通过率。同一实体/属性判断仍依赖模型；不能宣称确定性防住所有语义误合并。

本版不修复旧库已经漂移的组、不对同批首次出现的多个候选做互相归组、不实现条件逻辑求解或多目标争议解除。冲突摘要提取错误及模型输出截断仍是独立问题，不能以本切片通过测试宣称记忆整体成熟。

## 验证

确定性测试必须验证：词汇漂移归组、零分一般规则同行、条件/来源/时间不变、同条件冲突不能伪装成新事实、非法引用与失效目标待定、重建/重开一致、head 竞争重新复核、旧协议保持和模型适配器版本绑定。真实模型复用原自然形成数据，分别报告形成完成、结构评分与全链路状态，保留失败。结果与限制在阶段交付文档记录。

实测收益与失败见[事实族对齐实现与验证](../事实族对齐实现与验证.md)。
