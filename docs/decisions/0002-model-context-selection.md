# ADR 0002：当前任务与完整工具历史驱动的模型上下文选择

- 状态：采纳
- 日期：2026-10-11
- 范围：模型调用与上下文选择的离线切片

## 背景与目标

上下文不能只是一段不断追加的文本。用户改变约束时，当前输入需要独立于旧历史表达；选择历史时，不能留下没有调用的工具结果。有限预算下，还需要明确保证宿主指定的必要证据不会被近期无关内容挤掉。

本次实现一个可以实际调用 Fake Provider 的最小切片，对比完整历史、近期连续历史与必要证据优先的选择。它不实现完整 Agent Loop、自动任务规划、自然语言约束合并、语义检索、Artifact、摘要或 Memory。当前任务和证据依赖由宿主显式提供。

这是对原默认开发顺序的一次有范围的调整：根据项目所有者明确要求，提前验证 Harness 的上下文组织机制，同时只实现它所需的模型端口。后续 Runtime 仍负责事件、预算、工具副作用及生命周期，不由上下文选择器接管。

## 决策

1. 现有 V1 Message/AgentRequest/Action/Observation 不修改。新增 `TaskInput` 表示当前目标、约束和任务修订；它不是 RunState 或 Memory，也不是自动生成的事实。未来任务更新由 Runtime 接受的用户输入驱动；本步由宿主传入。
2. `ToolExchange` 包含一次结构化 ToolCallAction 和对应 Observation，严格验证调用标识与工具名称。选择以完整 Exchange 为单位。只有已完成的调用可进入本步历史；运行中的调用以后由 Runtime 表达。
3. `ModelRequest` 分开表达宿主指令、当前任务和历史。历史只接受 user/assistant 文本与完整工具 Exchange；不接受 system 文本和孤立 tool 文本。原始调用 ID 在一次输入历史内必须唯一。本步不实现供应商编码或 Prompt Injection 防御；工具输出仍是不可信数据。
4. 模型一轮只返回一个 `ModelResponse.action`。ModelProvider 明确声明工具调用能力；框架调用边界会重新校验请求和响应，拒绝能力不支持的响应，并归一化错误。调用有明确的相对超时，外部取消传播并等待当前 await 清理，不创建后台任务。未来 Runtime 用单调时钟将整体 Deadline 换算为剩余调用时间。
5. 模型请求使用精确的 UTF-8 JSON 字节预算。它度量框架归一化请求大小，不代表供应商实际 Prompt、Tokenizer 或 Token 用量。当前不伪造 Token 统计。
6. 上下文策略通过 `HistorySelector` Protocol 替换。框架控制校验、编码、预算和输出顺序，策略仅选择历史索引。完整历史保留全部项；近期策略保留能容纳的连续后缀；证据优先策略保留宿主指定的必要调用，再按新到旧填充可容纳的项，最终恢复原始时间顺序。
7. 声明保留必要证据的策略必须通过框架校验；必要证据不存在或无法容纳时明确失败。近期策略作为对比基线，可能丢失必要证据，选择报告必须显示这一点。所有策略都不能修改当前任务或宿主指令，不能产生越界、重复、乱序或超预算的最终输入。
8. 输入先经过重新校验并独立复制；选择结果保存序列化快照。访问该快照会生成新的 ModelRequest，后续修改原始嵌套 JSON 或取出的请求，不能改变已生成的上下文计划。它是一次模型输入快照，不是不可变 Runtime Event。
9. 选择报告记录策略版本、预算、源历史索引、调用标识与保留/省略原因，不默认输出内容。Fake Provider 的请求记录也使用独立快照，便于核对实际输入。

## 备选方案与取舍

- 把调用与结果编码成 Message.content：丢失结构与关联约束，拒绝。
- 建立通用多模态 Content Part 或多工具批次：本步尚无需求，暂缓；不以接口预留宣称已支持。
- 先做向量检索或 LLM 摘要：需要相关性、损失、成本和事实保真评测，超出本步。显式证据依赖可先验证选择机制，并暴露依赖发现尚未解决的限制。
- 全局最优背包：需要定义内容效用，本步没有可靠效用估计。采用确定性的必要证据优先加近期贪心填充，承认它不保证最优。
- 把模型调用错误返回为普通工具 Observation：混淆子系统失败与取消，拒绝。模型边界保留稳定错误分类和原始原因，但不直接记录原始异常内容。

## 验证与限制

使用冻结的合成资料与相同字节预算比较三个策略，记录请求是否可构建、必要证据是否保留、请求大小和历史项数。Fake Provider 证明输入到达与协议行为，不能证明自然语言答案、真实模型能力或 Token 成本改善。

契约测试覆盖正常返回、工具能力、错误、超时、取消和输入快照；上下文测试覆盖完整 Exchange、必要证据、精确预算、顺序、策略违规与嵌套数据修改。Core、models 与 context 增加静态依赖边界测试。
