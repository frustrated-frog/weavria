# 带来源的分层语义压缩与原文展开

## 问题与本阶段边界

现有编译器已经在完整请求的 Token/字节预算内分配原文、摘录和引用，但摘录压缩只提供短阅读线索，工作摘要只整理当前工作记录。长任务需要可组合的语义表示，并且必须能沿来源返回原文。

本阶段实现运行内、显式选择的语义压缩。模型通过 `compact_context` 提议带来源的摘要；工具验证读取范围后产出不可变 Artifact；编译器从已接受记录重建摘要 DAG，将摘要表示纳入现有覆盖分配器。摘要可以引用原文，也可以引用较早的完整摘要节点。父节点始终保留，展开仍使用 `recover_context` 的原文范围协议。暂不跨 Run 自动复用摘要，不把摘要转为长期 Memory，不增加隐式摘要模型调用。

## 设计与取舍

模型负责识别结论、条件、反例和未解决问题，并选择何时压缩、合并或回读。框架负责地址验证、层级展开、版本失效、重复覆盖消除和完整请求计量。采用显式工具是为了让生成摘要的模型调用、参数、失败和预算都沿现有 Runtime 记录；相较自动后台摘要，模型可能没有及时压缩，这是需要真实任务实验检验的限制。

摘要节点只保存直接来源和结构化陈述。编译时按接受顺序建立索引，展开已知摘要节点的来源，去重原文地址，并将陈述的来源下标映射到原始材料。只允许指向此前接受的节点，限制直接分支、深度和叶子数。任务版本变化时，旧摘要及依赖它的节点不进入活跃语义表示；原始材料继续参与新任务选择。

摘要调用以专门的模型视图交付，已消费历史的引用表示不重复携带生成时的大段参数。它与普通工具历史保持不同类型，避免省略参数后伪造一个执行动作。最新一轮反馈继续保留真实的动作—结果配对，并计入预算；任务版本变化后的旧摘要状态标记为 stale，不能用于新结论。摘要不产生原文交付证明，不满足证据验收。只有真正展开的原文继续进入 EvidenceDeliveryManifest。

摘要与原文使用同一预算分配器。摘要只按实际可见陈述评分，不用未展示原文词项冒充覆盖；同一需求词项饱和计分，原文仍有更高的信息质量权重。完整请求重新计量，父子摘要可以在子节点提供额外细节时同时入选。它是带冗余惩罚的分层多表示选择，不宣称全局最优。

## 不变量与失败语义

- 原文与摘要 Artifact 不可变；仅成功且已接受的工具记录进入图。
- 读取经过当前 Run 的 Artifact 授权，不能引用同批尚未接受的结果。
- 来源绑定完整 Artifact 身份、JSON Pointer、字符范围及内容摘要；验证地址不等于验证语义蕴含。
- 生成失败、无压缩收益或非法引用按普通工具失败返回；取消与超时由 Runtime 负责。
- 图的失效/拒绝以有界诊断反馈；不会删除原文，也不会把摘要当成新的证据。
- 图从持久记录重建，编译器缓存不是恢复事实。任务修订重新选择内容，旧结论不静默继承。
- 默认关闭，保持历史 Schema 的原样序列化；启用时使用显式的新请求和编译报告版本。

## 验证与完成标准

契约验证覆盖多层合并、来源去重、伪造/越界引用、任务修订、共享子节点、预算不足、取消、超时、存储恢复和原文展开。通过推荐 Harness 入口验证完整链路。提供文档/源码实验及现有摘录、语义压缩的对照，记录模型配置、资料摘要、任务结果、遗漏、引用和成本。确定性替身仅证明执行承诺；真实任务收益必须单独报告，默认策略的切换以收益证据为条件。
