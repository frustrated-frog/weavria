# 主动单读纠错的离线回放与旧版查询误用率

2026-11-25 使用上一轮 36 组初查与复查的 JSONL，以及两个领域各一条可复现的完整受控轨迹。离线执行期间外部模型调用为零。实验考察在同一会话、固定工具和资料集合中，已观察到一次主动纠错后，下次从两份可读资料中先读哪一份。基线保留提案顺序。误用指建议把原本能提供所需事实的首选，改成无法提供该事实的来源。

## 旧数据中只有一次可能改变首读

[自然形成实验](两个领域的单读反证自然形成与复用实验.md) 存下了实际读取序列、完整送达的来源、被接受的负向判断次数及结果。筛查要求首次只提议旧来源，恰好执行旧、新各一次，两个原文都送达，有一次绑定旧资料的负向判断，任务有当轮引用且答对，预算拒绝数和已索引的反证数均为零。

| 领域与轮次 | 策略 | 复查首次提案顺序 | 复查实际读取 | 改变首读的机会 |
| --- | --- | --- | --- | --- |
| 公交第 2 轮 | 排序并展示 | 公告、旧表 | 公告 | 0 |
| 公交第 3 轮 | 排序并展示 | 旧表、公告 | 旧表、公告 | 1 |
| 公交第 4 轮 | 普通 | 公告、旧表 | 公告 | 0 |

筛查覆盖全部 36 次初查，找到 3 次候选。其中展示组占 2/12，与上轮观察一致，软件归档占 0/18。即使三条都有合格的完整回执，按复查中实际提议的顺序，也只有公交第 3 轮可能把公告提前。一次改序能否少读一份资料仍取决于模型接下来的决策。

这批 JSONL 的 SHA-256 为 `1c5f0986e48547c21abe78e5543feee412f3e0b0df362e1a6c2840d1d7f57a90`。原临时数据库已清理，摘要缺少引句区间、精确交付轮次和原件。因此三条的 `trace_verified` 均为 `null`。这三个候选是本次筛查的结果，不能当作三条重新核验成功的回执，也不能据此计算实际节省的调用。

## 完整轨迹怎样形成回执

1. 实验从已完成 Run 中读取连续三个模型请求。对应决策依次为一次单读、改读另一份资料、依据后者提交终态答案。三个请求使用相同任务和修订，读取过程没有拒绝重试或额外模型轮次。本轮限于没有额外任务投影的冻结会话。
2. 将每个请求与 `ContextSelected` 的控制请求摘要对齐。带反馈时还核对完整传输请求摘要。针对前后两次读取，分别沿 call ID 定位 ToolRecord 与 Artifact，核对已授权的归一化入参、工具版本和内容摘要，再将重建出的完整交换与模型实际收到的交换逐字节比较。
3. 从第二次决策取失效判断，用指针和字符区间定位旧原件中的唯一原文，再核对引句摘要。替代来源须在下一轮完整送达，最终答案须引用它。这个条件说明模型采用了替代来源。所引用资料是否含有目标值由独立判分器检查。
4. 离线建议只在原任务、约束和修订摘要相同，两份来源的名称、工具版本及内容版本都匹配，且旧来源排在第一时改序。对照中的候选均已给定为可读，正式执行涉及的当次授权由 Runtime 独立负责。

自然实验的计量器现在会在数据库仍可读时保存核验结果和运行摘要。选择 `--trace-dir` 可以保留本批合成资料的 SQLite 原件。新摘要绑定有序执行事件与持久请求，回放可以发现同一初始请求被错误配上了另一段后续轨迹。[轨迹核验代码](../examples/direct_read_correction.py)

## 旧版查询的误用率

公交历史查询必须从撤回表取得 `22:45`，现行公告只有 `20:55`。归档历史查询必须从 4.1 版指南取得 `LZ4`，现行公告给出的默认值为 `ZSTD`。每个领域用受控替身提交一次完整的主动纠错，实际通过 SessionEngine 读两份资料、落库并核验。随后分别回放同一现行问题、明确询问旧版的问题和换一种说法的现行问题。每个问题分别使用旧版优先和新版优先两种顺序，每格共四个选源现场。判分检查首次选中的正文是否包含所需的唯一值。

| 离线策略 | 相同现行问题首读正确 | 历史问题首读正确 | 历史问题原本正确却被改错 | 改写现行问题首读正确 |
| --- | ---: | ---: | ---: | ---: |
| 保留提案顺序 | 2/4 | 2/4 | 0/2 | 2/4 |
| 仅按来源优先读替代资料 | 4/4 | 0/4 | 2/2 | 4/4 |
| 绑定任务及两个来源版本 | 4/4 | 2/4 | 0/2 | 2/4 |

绑定任务和版本后，历史问题中原本正确的两个首读都得到保留，原本排错的两个仍排错。精确匹配也错过了换一种说法的现行问题。两种候选顺序来自同一份轨迹，这些数字衡量固定现场中排序规则的行为，不能外推为自然任务的误用概率或回答成功率。

本次证据支持保留离线观测。扩大正式排序的依据仍不足。下一次自然复测可以保留完整原件，关注有多少条主动纠错能同时满足原文核验、复查命中、实际首选改变这三个条件，再检验模型是否减少后续读取。

## 复现

```bash
uv run --offline python -m examples.replay_direct_read_corrections
uv run --offline python -m examples.replay_direct_read_corrections --trials /path/to/trials.jsonl
uv run --offline pytest -q tests/test_direct_read_correction.py tests/test_natural_read_counterevidence.py
```

第一条独立运行全部受控比较。第二条同时筛查上一轮的六轮自然实验摘要。日后如已有新格式摘要和配对的原件，可在第二条命令追加 `--trace-dir /path/to/trace-dir` 重验候选。回归用例覆盖伪造引句、摘要错配、损坏原件、约束变化、来源版本变化以及不完整的实验批次。[回放入口](../examples/replay_direct_read_corrections.py) · [回归测试](../tests/test_direct_read_correction.py)
